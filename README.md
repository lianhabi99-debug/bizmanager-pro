# BizManager Pro

A comprehensive business management web application built with pure HTML, CSS, and JavaScript.

## Features

- Dashboard with interactive charts
- Products and inventory management
- Incoming stock tracking
- Sales recording with profit calculation
- Expenses management
- Capital tracking
- Reports (PDF, Excel, CSV)
- Calendar view
- Transaction history
- Dark/Light theme
- Import/Export JSON backup

## Live Demo

https://lianhabi99-debug.github.io/bizmanager-pro

## Technologies

- HTML5, CSS3, Vanilla JavaScript
- Chart.js, jsPDF, SheetJS, Font Awesome
- localStorage for data persistence
